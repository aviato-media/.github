# Aviato

Aviato is a personal media server by [Ato](https://ato.software).

Learn more at [avi.ato.software](https://avi.ato.software).

## Plugins

Aviato is extensible through plugins.

- **[Aviato issues](https://github.com/aviato-media/aviato/issues)** - view and report issues.
- **[Plugin directory](https://github.com/aviato-media/plugins)** — browse community and official plugins.
- **[Official plugins](https://github.com/aviato-media/official-plugins)** — plugins maintained by the Aviato team.
- **[Plugin SDK](https://github.com/aviato-media/plugin-sdk)** — build your own plugin.

## Documentation

Need help? See the docs at [avi.ato.software/docs](https://avi.ato.software/docs).
